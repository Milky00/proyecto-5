TaskFlow

Aplicación de gestión de tareas hecha con JavaScript puro (HTML, CSS y JS), sin frameworks.

Cómo usarla

Abrí index.html en el navegador.

Qué hace
Crear, completar y eliminar tareas
Poner fecha límite a una tarea, con cuenta regresiva
Notificaciones al agregar o eliminar tareas
Importar tareas de ejemplo desde una API
Guardar las tareas en localStorage
Archivos
index.html — estructura
style.css — estilos
script.js — lógica
Tecnologías

JavaScript ES6+, orientación a objetos, eventos del DOM, async/await, fetch API, localStorage.
